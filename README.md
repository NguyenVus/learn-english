# EnglishPath · A2 → B1 → B2

A complete, self-contained English learning website for Vietnamese learners, from **A2 to B2 (CEFR)**, covering **Reading, Listening, Speaking and Writing**. Everything is in a single file, `index.html`, with no installation and no external services.

## Run it

- Open `index.html` in **Google Chrome** or **Microsoft Edge**, or
- Serve the folder locally (recommended, so the microphone permission is remembered):

  ```bash
  python -m http.server 8080
  ```

  Then open http://localhost:8080.

## Features

- **Placement test** (25 questions) → A2, A2+, B1, B1+ or B2
- **Roadmap**: 3 stages × 5 units; a stage unlocks after its end-of-stage test (≥ 70%), and any level can still be chosen freely
- **Dashboard**: level, progress for each skill, streak, study time, words learned, weekly goal and "Today's plan" (~30 min, focused on the weakest skill)
- **Reading**: 15 passages per level; multiple choice, True/False/Not Given, gap-fill, matching and matching headings; click any word for its meaning, pronunciation and an example, and save it
- **Listening**: 9 recordings per level (Web Speech API); US/UK accent, 0.75×/1×/1.25× speed; multiple choice, gap-fill and dictation with highlighted differences
- **Speaking**: speech recognition, pronunciation feedback word by word (final consonants, /θ/ /ð/, /ʃ/ /s/, word stress), timed tasks with transcript, words per minute and useful phrases; self-review recording when recognition is not supported
- **Writing**: 8 tasks per level with model answers, an estimated rubric and automatic checks (word count, paragraphs, linking words, repetition, long sentences, level vocabulary, common mistakes); all answers saved
- **Grammar**: 9 lessons per level, each with Vietnamese notes and 10 questions
- **Vocabulary**: word banks by level and topic, phrasal verbs, collocations, common mistakes, and flashcards with spaced repetition
- **Guides**: 25 strategy guides covering every exercise type, each with mini practice, plus a "How to do this" box next to each exercise
- **Answer explanations**: evidence sentences from the text or recording, grammar rules and Vietnamese notes
- **Tests & progress**: unit tests, stage tests, a score chart, badges, and export/import of progress (stored in `localStorage`)
- Light/dark mode, responsive layout, Vietnamese explanations that can be toggled on or off

## Adding content

All content lives in structured JavaScript objects at the top of `index.html` (`DATA.reading`, `DATA.listening`, `DATA.speaking`, `DATA.writing`, `DATA.grammar`, `DATA.vocab`, `DATA.guides`, `DATA.units`), grouped by level. The supported question formats are documented in a comment just before the data section.

## Notes

- Audio is generated by the browser's own speech engine. If you can't hear anything, use the "🔈 Test audio" button and the "Audio not working?" help on any listening page.
- Speech recognition works in Chrome or Edge, on `localhost` or HTTPS.
- All texts are original content written for this project.
